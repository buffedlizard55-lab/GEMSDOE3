Hashes & measurement JSON

Grid 3,292 × 3,730 · EPSG:32611 · 5,167,373 template-valid pixels · 60,988 known positives. Byte hashes match the inherited mirror inventory; they are not new authenticated checksums from DrivenData.

Two important mismatches. The supplied sample contains 60,988 positive values despite the official all-absence description. 3,061 template-valid pixels have no finite feature band, and 1,540 feature pixels sit outside the template. Use the template mask, not the feature footprint. Embedded band meanings—particularly tc—are not independently certified geological interpretations.
